# Эмулятор командной оболочки (вариант 12)

## Общее описание

Консольное приложение, имитирующее работу в командной строке
UNIX-подобной ОС. Реализовано на Python 3 без сторонних библиотек.

Выполненные этапы:

1. **REPL** — приглашение, парсер, команды-заглушки.
2. **Конфигурация** — параметры командной строки, стартовый скрипт,
   команда `conf-dump`.

## Функции и настройки

### Параметры командной строки

| Параметр | Описание |
|---|---|
| `--vfs PATH` | путь к физическому расположению VFS |
| `--script PATH` | путь к стартовому скрипту |
| `-h`, `--help` | справка по параметрам |

При запуске эмулятор выводит все параметры (отладочный вывод):

```
[debug] vfs=/home/ivan/shell-emulator/vfs/minimal.zip
[debug] script=<not set>
```

### Стартовый скрипт

Текстовый файл с командами эмулятора, по одной в строке. Пустые
строки и строки, начинающиеся с `#`, пропускаются. При выполнении
на экран выводится и команда (после приглашения), и ее результат —
как при диалоге с пользователем.

- При первой ошибке скрипт останавливается, эмулятор завершается
  с кодом 1.
- Команда `exit` в скрипте завершает эмулятор с указанным кодом.
- Если скрипт выполнен полностью, эмулятор переходит
  в интерактивный режим.

### Приглашение и парсер

Приглашение к вводу формируется из реальных данных ОС:
`имя_пользователя@имя_хоста:~$`.

Ввод разбивается на команду и аргументы по пробелам
(аргумент с пробелами можно взять в кавычки: `cd 'my dir'`).

### Команды

| Команда | Описание |
|---|---|
| `ls [аргументы]` | заглушка: выводит имя команды и аргументы |
| `cd [путь]` | заглушка: выводит имя команды и аргумент; больше одного аргумента — ошибка |
| `exit [код]` | завершает работу с кодом возврата (по умолчанию 0) |
| `conf-dump` | выводит параметры эмулятора в формате `ключ=значение` |

### Обработка ошибок

- неизвестная команда — `foo: command not found`;
- неверные аргументы — `cd: too many arguments`,
  `exit: abc: numeric argument required`;
- незакрытая кавычка — `syntax error: No closing quotation`;
- ошибка в скрипте — `script: stopped at line N`;
- несуществующий скрипт — `script: [Errno 2] No such file...`.

Выход также по `Ctrl+D`; `Ctrl+C` сбрасывает текущую строку.

## Структура проекта

```
src/shell_emulator/   исходный код
tests/                модульные тесты
examples/             стартовые скрипты эмулятора
scripts/              скрипты ОС для запуска эмулятора с разными параметрами
run.sh                запуск эмулятора и тестов
```

## Сборка и запуск

Нужен Python 3.8+. Сборка не требуется.

```sh
./run.sh                                  # интерактивный режим
./run.sh --script examples/start.txt      # со стартовым скриптом
./run.sh test                             # запуск тестов
```

Скрипты для проверки параметров командной строки:

```sh
scripts/test_no_args.sh     # без параметров
scripts/test_vfs.sh         # только --vfs
scripts/test_script.sh      # только --script
scripts/test_all_args.sh    # оба параметра
scripts/test_errors.sh      # ошибочные ситуации
```

## Пример использования

```
$ ./run.sh --script examples/error.txt
[debug] vfs=<not set>
[debug] script=/home/ivan/shell-emulator/examples/error.txt
ivan@macbook:~$ ls
ls: args=[]
ivan@macbook:~$ cd /tmp
cd: args=['/tmp']
ivan@macbook:~$ cd a b
cd: too many arguments
script: stopped at line 4
```
